## Day 2 focus

- Use variables as typed module inputs.
- Use validation for allowed business values.
- Use locals for derived names, tags, and reusable expressions.
- Use outputs to expose selected infrastructure values.
- Understand primitive, collection, and object type constraints.
- Use `terraform validate`, `terraform plan`, `terraform console`, and `terraform output` while troubleshooting.
- Recover safely from invalid variable types without weakening production module contracts.

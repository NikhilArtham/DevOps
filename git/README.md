# Git

Git notes for Linux/AWS/DevOps work, written beginner-first and focused on production troubleshooting and interview readiness.

## Study Structure

- `DAY X - topic.md` → learning notes only
- `LABS.md` → all practical Git labs
- `INTERVIEW QUESTIONS.md` → all Git interview questions
- `README.md` → Git learning path and progress

**Do not create separate per-day LABS or INTERVIEW QUESTIONS files.**

DAY numbering starts at `DAY 1` independently for Git.

## Progress

- [DAY 1 - Git Internals: Objects, HEAD, Refs and Reflog](DAY%201%20-%20Git%20Internals%20Objects%20HEAD%20Refs%20and%20Reflog.md) — Git objects, blobs, trees, commits, refs, branches, HEAD, detached HEAD, reflog, `git cat-file`, `git rev-parse`, `git show-ref`, `git fsck`, and recovery after accidental reset.
- [DAY 2 - Git Branching, Merge vs Rebase and Conflict Recovery](DAY%202%20-%20Git%20Branching%20Merge%20vs%20Rebase%20and%20Conflict%20Recovery.md) — branching, fast-forward and three-way merges, rebase, conflict resolution, abort/continue workflows, branch divergence, and safe force-pushing.
- [DAY 3 - Pull Requests, Code Review and Clean Commit History](DAY%203%20-%20Pull%20Requests%20Code%20Review%20and%20Clean%20Commit%20History.md) — PR workflow, source vs base branches, review practices, CI checks, commit quality, interactive rebase, squash/fixup, branch protection, and DevOps/AWS review scenarios.
- [DAY 4 - Git Reset, Revert, Cherry-pick and Recovery Lab](DAY%204%20-%20Git%20Reset%20Revert%20Cherry-pick%20and%20Recovery%20Lab.md) — reset modes, safe rollback with revert, targeted hotfixes with cherry-pick, conflict recovery, reflog-based recovery, and production Kubernetes/Terraform failure scenarios.
